# 🎬 스토리보드 생성기 (Storyboard Generator)

대본을 넣으면 AI가 분석해 **촬영용 샷 콘티(흑백)** 와 **영상 생성 AI용 영어 프롬프트**를 만들어 주는 웹 앱입니다. 프로젝트 단위로 관리되며, 씬을 이어붙여도 분위기·등장인물·작화 톤이 일관되게 유지됩니다.

## 주요 기능

- **3개 AI 지원**: Claude / Gemini / GPT 중 선택해 본인 API 키로 사용
- **긴 대본 완전 분해**: 씬 단위로 나눠 모든 내용을 빠짐없이 콘티화
- **전문 촬영 항목**: 샷 넘버 · 샷 사이즈 · 앵글 · 카메라 무빙 · 렌즈 · 구도 · 액션 · 대사 · 음향 · 길이 · 트랜지션
- **흑백 선화 프레임**: 샷 사이즈에 맞춰 인물·구도를 자동 렌더링 (3분할 가이드, 카메라 무빙 화살표)
- **프로젝트 관리 + 기억**: 스타일 메모리·등장인물·배경을 저장해 이어지는 씬에 일관 적용
- **영상 스타일**: 실사 / 애니메이션 / BL 숏폼 드라마 + 그림체(작화 톤) 선택
- **PDF 내보내기**: 표지 + 씬별 콘티집

## 사용법

1. 사이트를 연다
2. AI 모델을 고르고 본인 **API 키**를 입력 (키는 본인 브라우저에만 저장됨)
3. 프로젝트 설정(스타일·등장인물 등)을 입력
4. 대본을 붙여넣고 **생성** → 콘티 + 영어 프롬프트 확인
5. 영어 프롬프트를 복사해 이미지/영상 생성 AI에 사용

## 개인정보 / 보안

- API 키는 **코드에 포함되지 않습니다.** 각 사용자가 자기 브라우저(localStorage)에 입력·저장하며, 선택한 AI사로만 직접 전송됩니다.
- 따라서 이 저장소를 **공개(public)** 로 배포해도 안전합니다.

## 배포 (Vercel)

정적 단일 HTML이라 별도 빌드가 필요 없습니다. GitHub 저장소를 Vercel에 연결하면 `index.html`이 자동으로 루트에서 서비스됩니다.

## 기술

순수 HTML/CSS/JavaScript 단일 파일. 외부 라이브러리는 CDN으로 로드(jsPDF, html2canvas).
